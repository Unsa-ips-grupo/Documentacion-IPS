Krayin CRM

Proyecto Principal · CRM

03 El producto final: 6 entregables
El producto evaluable no es Krayin CRM. Es la aplicación rigurosa de un proceso de Ingeniería de Software (Scrum + DevOps) sobre Krayin CRM como caso de estudio.
01
Fork con mejoras implementadas
Una o dos funcionalidades nuevas o extensiones a módulos existentes de Krayin, mergeadas vía pull request al fork de la organización.
Sprint 3 · Hito 3
02
Pipeline CI/CD en GitHub Actions
Workflow YAML que ejecuta PHPUnit, Pest y Laravel Pint en cada push o pull request. Badge de build en el README.
Sprint 2 · Hito 2 ★
03
Despliegue automatizado a staging
Krayin desplegado en la nube (Railway, Render o VPS) y actualizado automáticamente con cada merge a main vía GitHub Actions.
Sprint 3 · Hito 3
04
Documentación Scrum completa
Sprint Reviews, Retrospectivas y backlog trazables en el repositorio. Evidencia real de la aplicación de Scrum, no solo tarjetas movidas.
Todos los sprints
05
Artículo en formato IEEE
Paper académico documentando contexto, marco teórico de Scrum/DevOps, decisiones técnicas, resultados y conclusiones del proceso completo.
Sprint 4 · Hito 3 ★
06
Demostración final en vivo
Presentación técnica mostrando el pipeline CI/CD ejecutándose, el entorno de staging accesible y las mejoras implementadas funcionando.
